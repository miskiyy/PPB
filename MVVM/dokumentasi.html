📌 Student Registration App

Aplikasi pengelolaan pendaftaran data siswa secara lokal dengan arsitektur modern Android development.

Student Registration App adalah aplikasi Android berbasis Kotlin yang dirancang untuk mengelola data siswa menggunakan konsep CRUD (Create, Read, Update, Delete) secara reaktif. Aplikasi ini dibangun dengan framework UI deklaratif Jetpack Compose, didukung oleh Room Database sebagai media penyimpanan relasional lokal offline, serta memanfaatkan KSP (Kotlin Symbol Processing) yang menggantikan kapt untuk kompilasi kode Room yang lebih cepat.

📝 Entri Data (Create)

Memasukkan data siswa berupa Nama Lengkap dan Alamat Email melalui formulir input reaktif.

📖 Daftar Dinamis (Read)

Menampilkan data secara real-time dari Room Database menggunakan Flow yang dikonversi menjadi state.

✏️ Pembaruan Data (Update)

Fitur edit interaktif. Klik edit memindahkan data ke form input untuk diperbarui secara real-time.

🗑️ Penghapusan (Delete)

Menghapus data siswa secara langsung dari database dengan tombol hapus yang responsif.

🛡️ Validasi Input

Mencegah data kosong, memeriksa kelengkapan form, serta memvalidasi format email (wajib berisi '@').

🎨 Material Design 3

Menerapkan palet warna Pink yang premium, dynamic color, rounded corner, card modern, dan placeholder cantik saat kosong.

📐 Arsitektur MVVM (Model-View-ViewModel)

Pola pemisahan logika bisnis dari UI untuk skalabilitas, kemudahan testing, dan kebersihan kode.

Aplikasi ini diimplementasikan dengan pola arsitektur Model-View-ViewModel (MVVM) standar industri Android modern. Pendekatan ini memisahkan UI (Jetpack Compose) dari data layer (Room Database) melalui perantara ViewModel yang mengelola state data secara lifecycle-aware. Di bawah ini adalah visualisasi interaktif dari Unidirectional Data Flow (UDF) yang diterapkan pada aplikasi ini:

⇄

⇄

Model (Data Layer)

Room DB / Siswa / DAO
View (Presentation Layer): Terdiri dari MainScreen, FormInput, dan StudentItem yang dibangun secara deklaratif dengan Jetpack Compose. Mengamati status flow (state) dari ViewModel secara reaktif melalui collectAsState() dan mengirimkan event (seperti submit form atau klik tombol edit/hapus) ke ViewModel. Lapisan ini tidak memiliki pengetahuan tentang SQL atau database fisik.

Karakteristik Teknis Alur Data:

  • Thread Isolation: UI berjalan sepenuhnya di Main Thread, sedangkan transaksi tulis database (insert, update, delete) didelegasikan oleh Room secara asinkronus ke thread latar belakang (menggunakan Coroutines di bawah viewModelScope).
  • Single Source of Truth (SSOT): SQLite/Room bertindak sebagai satu-satunya sumber data valid. Perubahan data di layar tidak diupdate langsung ke variabel lokal UI, melainkan ditulis ke Room, lalu mengalir kembali ke UI sebagai aliran data reaktif baru.
  • Lifecycle-Aware State Preservation: ViewModel tetap bertahan di memori saat terjadi pemusnahan & pembuatan ulang Activity (seperti rotasi layar), mencegah kehilangan data input atau status form.

package com.example.studentapp.data

import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase

@Database(
    entities = [Siswa::class],
    version = 1
)
abstract class AppDatabase : RoomDatabase() {
    abstract fun siswaDao(): SiswaDao

    companion object {
        @Volatile
        private var INSTANCE: AppDatabase? = null

        fun getDatabase(context: Context): AppDatabase {
            return INSTANCE ?: synchronized(this) {
                val instance = Room.databaseBuilder(
                    context.applicationContext,
                    AppDatabase::class.java,
                    "siswa_database"
                ).build()
                INSTANCE = instance
                instance
            }
        }
    }
}
📄 StudentViewModel.kt (ViewModel)

package com.example.studentapp.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.example.studentapp.data.Siswa
import com.example.studentapp.data.SiswaDao
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

class StudentViewModel(
    private val dao: SiswaDao
) : ViewModel() {
    // Mengonversi Flow dingin dari Room menjadi StateFlow panas yang lifecycle-aware
    val siswaList = dao.getAllSiswa()
        .stateIn(
            scope = viewModelScope,
            started = SharingStarted.WhileSubscribed(5000),
            initialValue = emptyList()
        )

    fun tambahSiswa(nama: String, email: String) {
        viewModelScope.launch {
            dao.insertSiswa(
                Siswa(
                    nama = nama,
                    email = email
                )
            )
        }
    }

    fun hapusSiswa(siswa: Siswa) {
        viewModelScope.launch {
            dao.deleteSiswa(siswa)
        }
    }

    fun editSiswa(siswa: Siswa) {
        viewModelScope.launch {
            dao.updateSiswa(siswa)
        }
    }
}

package com.example.studentapp.ui

import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.text.style.TextAlign
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import com.example.studentapp.data.Siswa
import com.example.studentapp.viewmodel.StudentViewModel

@OptIn(ExperimentalMaterial3Api::class)
@Composable
fun MainScreen(
    viewModel: StudentViewModel
) {
    // Local input state variables
    var nama by remember { mutableStateOf("") }
    var email by remember { mutableStateOf("") }
    var editingSiswa by remember { mutableStateOf(null) }
    
    // Obsever stateFlow reaktif dari database Room
    val siswaList by viewModel.siswaList.collectAsState()

    Scaffold(
        topBar = {
            TopAppBar(
                title = {
                    Text(
                        text = "Registrasi Siswa",
                        fontWeight = FontWeight.Bold,
                        color = MaterialTheme.colorScheme.onPrimary
                    )
                },
                colors = TopAppBarDefaults.topAppBarColors(
                    containerColor = MaterialTheme.colorScheme.primary
                )
            )
        },
        containerColor = MaterialTheme.colorScheme.background
    ) { innerPadding ->
        Column(
            modifier = Modifier
                .fillMaxSize()
                .padding(innerPadding)
                .padding(16.dp)
        ) {
            Text(
                text = if (editingSiswa != null) "Edit Data Siswa" else "Tambah Siswa Baru",
                style = MaterialTheme.typography.titleLarge,
                fontWeight = FontWeight.Bold,
                color = MaterialTheme.colorScheme.primary,
                modifier = Modifier.padding(bottom = 4.dp)
            )
            Text(
                text = if (editingSiswa != null) "Perbarui nama dan email siswa" else "Kelola dan daftarkan data siswa baru",
                style = MaterialTheme.typography.bodyMedium,
                color = MaterialTheme.colorScheme.onBackground.copy(alpha = 0.6f),
                modifier = Modifier.padding(bottom = 16.dp)
            )

            FormInput(
                nama = nama,
                email = email,
                onNamaChange = { nama = it },
                onEmailChange = { email = it },
                isEditMode = editingSiswa != null,
                onActionClick = {
                    if (nama.isBlank() || email.isBlank() || !email.contains("@")) {
                        return@FormInput
                    }
                    val currentEdit = editingSiswa
                    if (currentEdit != null) {
                        viewModel.editSiswa(
                            currentEdit.copy(nama = nama.trim(), email = email.trim())
                        )
                        editingSiswa = null
                    } else {
                        viewModel.tambahSiswa(nama.trim(), email.trim())
                    }
                    nama = ""
                    email = ""
                },
                onBatalClick = {
                    nama = ""
                    email = ""
                    editingSiswa = null
                }
            )

            Spacer(modifier = Modifier.height(24.dp))
            HorizontalDivider(color = MaterialTheme.colorScheme.outline.copy(alpha = 0.5f))
            Spacer(modifier = Modifier.height(16.dp))

            Text(
                text = "Daftar Siswa Terdaftar",
                style = MaterialTheme.typography.titleMedium,
                fontWeight = FontWeight.Bold,
                color = MaterialTheme.colorScheme.primary,
                modifier = Modifier.padding(bottom = 12.dp)
            )

            if (siswaList.isEmpty()) {
                Box(
                    modifier = Modifier
                        .fillMaxWidth()
                        .weight(1f),
                    contentAlignment = Alignment.Center
                ) {
                    Column(horizontalAlignment = Alignment.CenterHorizontally) {
                        Text(
                            text = "🌸",
                            fontSize = 48.sp,
                            modifier = Modifier.padding(bottom = 8.dp)
                        )
                        Text(
                            text = "Belum ada data siswa",
                            style = MaterialTheme.typography.bodyLarge,
                            fontWeight = FontWeight.Medium,
                            color = MaterialTheme.colorScheme.onBackground.copy(alpha = 0.5f),
                            textAlign = TextAlign.Center
                        )
                    }
                }
            } else {
                LazyColumn(
                    modifier = Modifier.weight(1f),
                    contentPadding = PaddingValues(bottom = 16.dp)
                ) {
                    items(siswaList, key = { it.id }) { siswa ->
                        StudentItem(
                            siswa = siswa,
                            onDelete = {
                                if (editingSiswa?.id == siswa.id) {
                                    editingSiswa = null
                                    nama = ""
                                    email = ""
                                }
                                viewModel.hapusSiswa(siswa)
                            },
                            onEdit = {
                                editingSiswa = siswa
                                nama = siswa.nama
                                email = siswa.email
                            }
                        )
                    }
                }
            }
        }
    }
}

🔄 Konsep State Management

Memahami bagaimana state dikelola, disimpan, dan diturunkan untuk menghasilkan UI reaktif.

remember & mutableStateOf

Digunakan di MainScreen untuk melacak string input formulir secara lokal (nama dan email) serta objek editingSiswa yang sedang diedit. remember mempertahankan nilai state saat recomposition terjadi.

stateIn()

Di StudentViewModel, cold Flow dari Room Database dikonversi menjadi hot StateFlow yang lifecycle-aware menggunakan operator stateIn(...) dengan konfigurasi SharingStarted.WhileSubscribed(5000) untuk menghemat resource.

collectAsState()

Fungsi ekstensi Compose untuk mengamati StateFlow dari ViewModel. Memicu pembaruan otomatis list UI LazyColumn secara instan setiap kali isi database berubah.

State Hoisting

Memindahkan local state (nama, email, action click) ke level MainScreen, lalu menyalurkannya ke FormInput. Hal ini membuat FormInput bersifat stateless, bersih dari logika, dan mudah digunakan kembali.

🔁 Alur Kerja Operasi CRUD

Perjalanan data dari input pengguna hingga tersimpan permanen di database lokal SQLite.

1. Input & Validasi
Pengguna menulis data di form. Saat mengklik "Tambah", Compose melakukan validasi: nama tidak boleh kosong, email tidak boleh kosong, dan harus mengandung karakter '@'. Jika lolos, trigger aksi ViewModel.
2. ViewModel Launch Coroutine
ViewModel menerima input dan menjalankan coroutine asinkron (viewModelScope.launch) untuk memicu fungsi insert/update pada DAO tanpa memblokir thread UI utama.
3. Penyimpanan SQLite via Room
Room DAO melakukan query SQL insert/update/delete langsung pada database internal SQLite perangkat secara aman di background thread.
4. Emit & Recomposition
Karena query mengembalikan Flow, database memancarkan data terbaru secara otomatis. collectAsState di UI mendeteksi perubahan ini dan memicu Recomposition untuk memperbarui list visual di layar seketika.
